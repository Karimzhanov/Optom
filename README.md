# Optom Product Osh — Django backend

## Что сделано
- Django Jazzmin с русской панелью администратора.
- Категории и товары управляются через Django admin.
- Скрытый slug категории генерируется автоматически; порядок категорий задаётся через «Порядок сортировки».
- У товара есть розничная и оптовая цена.
- Основная единица продажи: `шт.`, `кг` или `л`.
- Упаковка (`мешок`, `блок`, `коробка`, `ящик`) — только информация о фасовке, это не отдельный способ продажи.
- Остаток в админке задаётся количеством упаковок. Для товара без упаковки это количество основной единицы.
- Магазин сам пересчитывает внутренний остаток в основной единице.
- В карточке и модальном окне всегда доступны только «Розница» и «Опт».
- Корзина не удаляет товар из каталога после добавления; товар получает статус «Нет в наличии» только когда реального остатка больше нет.
- Поиск и фильтр категорий работают на одной странице.
- Оформление заказа атомарно уменьшает остаток и сохраняет заказ.
- После заказа открывается WhatsApp с составом заказа и ссылками на фото.

## Запуск
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py fill_db
python manage.py createsuperuser
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/
Админка: http://127.0.0.1:8000/admin/

## Фото в WhatsApp
Обычная ссылка `wa.me` не прикрепляет файл изображения автоматически. Поэтому в сообщение добавляется URL фото. Для настоящего вложения файлов нужен WhatsApp Cloud API / Meta Business.


## Заполнение каталога
После `migrate` можно выполнить `python manage.py fill_db`. Команда добавит готовые категории и товары с розничными/оптовыми ценами и остатками в упаковках. Существующие товары не перезаписываются.


## Быстрый запуск

После распаковки проекта и активации `venv`:

```powershell
python manage.py fill_db
python manage.py runserver
```

`fill_db` теперь сначала автоматически выполняет Django migrations, поэтому на чистом `db.sqlite3` ошибка `no such table: shop_category` не возникает. Команда заполняет 6 категорий и 25 товаров, включая цены, остатки, упаковки и ссылки на изображения.

### Поиск

Поиск поддерживает несколько слов одновременно, регистр не важен, а `ё` и `е` считаются одинаковыми. Поиск работает по названию товара, описанию, категории, единице и упаковке и не ломается при выборе категории.

API также поддерживает:

```text
/api/products/?q=чай черный
/api/products/?category=napitki
/api/products/?q=coca&category=napitki
```
